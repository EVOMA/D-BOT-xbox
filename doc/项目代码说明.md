# D-BOT-xbox 项目代码说明文档

## 项目概述

D-BOT-xbox 是一个基于 ESP32-S3 的智能机器人控制项目，支持多种控制模式，包括 Xbox 手柄控制、自平衡模式和旋钮控制模式。项目使用 Arduino 框架开发，集成了电机控制、IMU 传感器、无线通信和图形界面等功能。

### 主要功能
- Xbox 手柄蓝牙控制
- 自平衡运动控制
- 旋钮模式控制
- UDP 网络通信
- MQTT 消息通信
- LVGL 图形用户界面
- 电机 FOC 控制
- IMU 姿态感知

## 核心模块说明

### 1. 主程序 ([main.cpp](src/main.cpp))

**功能**：系统初始化和主循环

**关键函数**：
- `dbot_init()`: 初始化通信模块、机器人控制和手柄控制
- `setup()`: 系统启动入口，初始化 NVS、HAL、DBot 和 App
- `loop()`: 主循环，调用 HAL::Update() 更新系统状态

**调用链**：
```
setup() 
  → nvs_init()
  → HAL::Init()
  → dbot_init()
    → 初始化 UDP 通信
    → 初始化 DBot
    → 初始化 Xbox 手柄
  → App_Init()

loop()
  → HAL::Update()
```

### 2. 机器人控制 ([src/app/bot/](src/app/bot/))

#### 2.1 [bot.h/cpp](src/app/bot/bot.h) - 核心控制类

**功能**：机器人运动控制和命令管理

**关键成员**：
- `commandQueue`: 命令队列
- `target_yaw`: 目标偏航角
- `_comms`: 通信模块列表

**控制模式枚举**：
```cpp
enum bot_control_type {
    BOT_CONTROL_TYPE_AI,        // AI 控制
    BOT_CONTROL_TYPE_JOYSTICKS, // 手柄摇杆控制
    BOT_CONTROL_TYPE_MAX
};
```

**命令类型**：
```cpp
enum class CommandType {
    SPIN,  // 旋转
    MOVE   // 移动
};
```

**关键函数**：
- `init()`: 初始化通信回调和任务
- `spin(double angel)`: 添加旋转命令
- `move(double distance)`: 添加移动命令
- `handleMessage(const JsonDocument& json)`: 处理网络消息

**定位技巧**：
- 修改命令处理逻辑 → `handleMessage()` 函数
- 修改运动参数 → `pid_bot_s` (转向) 和 `pid_bot_m` (移动)
- 添加新命令类型 → 在 `CommandType` 中添加并修改 `handleMessage()`

#### 2.2 [controller.cpp](src/app/bot/controller.cpp) - Xbox 手柄控制

**功能**：解析 Xbox 手柄输入并控制机器人

**按键处理**：
- A 键：切换控制模式
- B 键：切换到 AI 模式并原地旋转 90 度
- 方向键：预留接口

**摇杆控制**：
- 左摇杆 X 轴：转向控制
- LT/RT 扳机：前进/后退速度

**关键函数**：
- `controller_init(const char *ble_addr)`: 初始化手柄连接
- `controller_update_task()`: 手柄更新任务（10ms 周期）
- `controller_set_motor_status()`: 将手柄输入转换为电机控制信号

**定位技巧**：
- 修改按键功能 → 修改 `controller_btn_x_handler()` 函数
- 修改摇杆灵敏度 → 调整 `_map()` 函数的参数
- 修改死区范围 → 在 `controller_set_motor_status()` 中添加

#### 2.3 通信模块 ([comm/](src/app/bot/comm/))

**基类接口** ([simple_comm.h](src/app/bot/comm/simple_comm.h))：
```cpp
class SimpleComm {

```

**UDP 通信** ([udp_comm.cpp](src/app/bot/comm/udp_comm.cpp))：
- 使用 UDP 端口 6090
- 支持 JSON 格式消息
- 用于接收远程控制命令

**定位技巧**：
- 修改通信协议 → 修改 `Loop()` 函数中的 JSON 解析
- 添加新通信方式 → 继承 `SimpleComm` 类

### 4. 硬件抽象层 ([src/hal/](src/hal/))

#### 4.1 [hal.h](src/hal/hal.h) - HAL 接口定义

**命名空间**：`HAL`

**运动模式枚举**：
```cpp
enum BOT_RUNNING_MODE {
    BOT_RUNNING_MODE,      // 普通模式
    BOT_RUNNING_XKNOB,    // 旋钮模式
    BOT_RUNNING_BALANCE,   // 自平衡模式
};
```

**关键接口**：
- `motor_init()`: 电机初始化
- `motor_set_speed(float speed, float steering)`: 设置速度和转向
- `imu_init()`: IMU 初始化
- `imu_get_pitch()`, `imu_get_yaw()`, `imu_get_gyro_z()`: 获取姿态数据
- `network_init()`: 网络初始化
- `mqtt_init()`: MQTT 初始化

#### 4.2 [motor.cpp](src/hal/motor.cpp) - 电机控制

**功能**：基于 SimpleFOC 库的电机 FOC 控制

**电机配置**：
- 支持 2 个电机（motor_0, motor_1）
- 使用 MT6701 磁编码器
- SPI 通信读取角度

**控制模式**：
1. **自平衡模式** (`run_balance_task()`)：
   - 使用 IMU 姿态数据
   - PID 控制：平衡 (pid_stb) + 速度 (pid_vel) + 转向 (pid_steering)
   - 参数位置：第 38-59 行

2. **旋钮模式** (`run_knob_task()`)：
   - 模拟旋钮触感
   - 支持多种触感配置
   - 配置数组 `x_knob_configs[]`

**关键函数**：
- `motor_init()`: 电机初始化和 FOC 校准
- `motor_task()`: 电机控制主任务
- `motor_set_speed()`: 设置目标速度和转向

**定位技巧**：
- 修改平衡参数 → 调整第 38-59 行的 PID 参数
- 修改旋钮触感 → 修改 `x_knob_configs[]` 数组
- 修改最大速度 → 修改 `MOTOR_MAX_SPEED` 宏

#### 4.3 [imu.cpp](src/hal/imu.cpp) - IMU 传感器

**功能**：读取和处理 IMU 数据

**支持芯片**：
- V0.1 版本：MPU6050
- V1.0 版本：BMI270 + Kalman 滤波

**数据结构**：
```cpp
struct imu_data {
    float angle_x, angle_y, angle_z;  // 欧拉角
    float gyro_z, gyro_x, gyro_y;     // 角速度
};
```

**关键函数**：
- `imu_init()`: 初始化 IMU 并校准
- `imu_update()`: 更新 IMU 数据（5ms 周期）
- `imu_get_pitch()`: 获取俯仰角（用于平衡控制）
- `imu_get_yaw()`: 获取偏航角（用于转向）
- `imu_get_gyro_z()`: 获取 Z 轴角速度

**定位技巧**：
- 修改校准逻辑 → `calc_gyro_offsets()` 函数
- 修改滤波参数 → `kalman_init()` 或滤波系数
- 修改 IMU 型号支持 → 添加 `#ifdef` 条件编译

#### 4.4 [network.cpp](src/hal/network.cpp) - 网络管理

**功能**：WiFi 连接和参数配置

**配置项**：
- Xbox 手柄蓝牙地址
- MQTT 服务器地址和端口
- MQTT 主题前缀

**配置方式**：
- 使用 WiFiManager 配置
- 配置完成后保存到 NVS
- AP 名称：`DBOT_` + MAC 地址后 6 位

**定位技巧**：
- 修改配置参数 → 添加新的 `WiFiManagerParameter`
- 修改 AP 名称 → 修改 `apName` 生成逻辑

## 常见问题

### 如何修改自平衡效果？
调整 [motor.cpp](src/hal/motor.cpp:38-47) 中的 PID 参数：
- `pid_stb`: 平衡控制（俯仰角）
- `pid_vel`: 速度控制
- `pid_steering`: 转向控制

### 如何修改旋钮触感？
调整 [motor.cpp](src/hal/motor.cpp:71-179) 中的 `x_knob_configs[]` 数组，选择不同的模式：
- `MOTOR_UNBOUND_FINE_DETENTS`: 精细阻尼
- `MOTOR_UNBOUND_NO_DETENTS`: 无阻尼
- `MOTOR_COARSE_DETENTS`: 粗糙棘轮
- `MOTOR_ON_OFF_STRONG_DETENTS`: 开关模式

### 如何切换控制模式？
1. 手柄：按 A 键切换
2. 姿态切换：根据 IMU 俯仰角自动切换（见 [motor.cpp](src/hal/motor.cpp:566-606)）

### 如何添加新的 MQTT 主题？
1. 在 [network.cpp](src/hal/network.cpp:18-21) 添加配置参数
2. 在 [hal.h](src/hal/hal.h:105-109) 实现 `mqtt_subscribe()`
3. 添加订阅回调函数

## 代码规范

### 命名约定
- 文件名：小写 + 下划线，如 `motor_controller.cpp`
- 类名：大驼峰，如 `BLECtrl`
- 函数名：小驼峰，如 `motor_init()`
- 宏定义：大写 + 下划线，如 `MOTOR_MAX_SPEED`
- 成员变量：小写 + 下划线，如 `g_throttle`

### 日志宏
```cpp
log_e("错误信息");  // ERROR
log_w("警告信息");  // WARN
log_i("信息输出");  // INFO
log_d("调试信息");  // DEBUG
log_v("详细日志");  // VERBOSE
```

### 任务创建
```cpp
xTaskCreatePinnedToCore(
    task_function,       // 任务函数
    "TaskName",         // 任务名称
    stack_size,         // 栈大小
    parameter,          // 参数
    priority,           // 优先级
    &handle,            // 任务句柄
    core_id             // 运行核心
);
```
